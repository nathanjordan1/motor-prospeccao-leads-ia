# 🎯 Motor de Prospecção e Mineração de Leads com IA

> Sistema automatizado para mineração, validação de dados e prospecção ativa de clientes B2B.  
> Desenvolvido por **Nathan Jordan de Oliveira** | Stack: `JavaScript` · `Node.js` · `Web Scraper` · `PostgreSQL`

## 🌟 Visão Geral

Plataforma de mineração de contatos, validação de e-mails/telefones corporativos e distribuição automática de oportunidades para equipes de vendas.

## 🛠️ Tecnologias

- **Linguagem**: JavaScript / Node.js
- **Automação**: Puppeteer / Playwright / Webhooks
- **Banco de Dados**: PostgreSQL
